Work

ZimClassLive

Solo project, multi-tenant school platform

A school management system for Zimbabwean schools, where each school’s data stays separate from every other school’s. It covers fees, attendance, grading and report cards. Features I built include phone-number login, role-based access, CSV import with two-pass validation, audit logs, GPS-verified staff clock-in and PDF report cards. An AI-assisted calendar reader proposes term dates, but a person must review them before anything is saved.

EduSync

The first version of ZimClass

My first full system, written in plain HTML, CSS and JavaScript on top of a Supabase backend. It handled parents with several children, proof-of-payment uploads with approve and reject actions, and fee reminders over WhatsApp. I rebuilt it in React once the number of pages and roles made the plain version hard to maintain.
